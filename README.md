# Ticklit
## Description
This is a web app I created to promote stock literacy by relating common stock terms to the stock with the second highest market app - Apple Inc.

This fetches data from twelvedata and finnhub and implements Cloudflare KV.

## AI Usage
I took the help of AI to develop the worker which fetched data and cached it in Cloudflare KV.
